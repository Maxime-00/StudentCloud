# Studentencloud

Studentencloud is een interne Nextcloud-omgeving voor studenten en projectgroepen.
Bestanden opslaan, delen en synchroniseren gebeurt via **https://10.20.254.141**.

Dit project is gebaseerd op de [officiële opdracht: Project 9 — Studentencloud voor bestanden](https://github.com/MathieuLeroy2/network-experience-2627/blob/main/projecten/09-studentencloud.md).

De functies uit de gebruikersgids zijn doorlopen en werken.
Afzonderlijke formele acceptatietests maken geen deel uit van de oplevering.
De documentatie beschrijft het gebruik en beheer.
